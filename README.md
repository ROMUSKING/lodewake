# Lodewake

Reverse-minesweeper space salvage. Extract lodestones from veil lattices, fit six double-edged keels, and keep the bay working while you look away.

Playable design lives in [`docs/DESIGN.md`](docs/DESIGN.md). Current status in [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Loop

1. Probe empty plates to read lode-marks (adjacent lodestone counts).
2. Extract the lodestones. Mark rifts. Chord a satisfied number.
3. Recall with the take, or push a perfect clear for fold shards.
4. Spend scrap on drones. Spend isotopes on keels that always charge interest.
5. Fold when the curve flattens.

## Stack

TanStack Start, React 19, Zustand, DOM grid. Save is local. No accounts.
